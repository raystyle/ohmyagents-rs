# G005-中英文技术文档字符与标点硬禁令

> 版本 v1.0（2026-09-02，源自用户提供的《中英文 Markdown 技术文档写作规范》转档）。与 G001 分工：G001 管命名与结构，本细则管**字符与标点**。目标：智能体输出无 AI 写作痕迹（em dash、箭头、emoji、全角误用）、可被机械校验。**封闭豁免清单模式**（ohmypwsh 总台落地经验，2026-09-02）：存量带病文件 52 个一次性入 `.tools\md-char-allow.txt` 只减不增（新文件不进清单强制合规，清理一处删一行）；diary 与 proven 历史归档及 node_modules 第三方由脚本整体跳过；`uv run --script .tools\mdcharlint.py` 已进验证链即刻生效。存量清理是独立队列项，清零后删清单。

## 硬禁令四类

1. **破折号与连接号**：禁止 `—`（U+2014）、`——`、`–`（U+2013）、`―`（U+2015）、正文 `−`（U+2212）、中文文档 `ー`（U+30FC）。替代：补充说明用冒号、括号或拆句；数值范围中文「3 至 5」、英文 `3-5`。半角连字符 `-` 合法（复合词、CLI 参数、范围）。
2. **箭头**：U+2190 至 U+21FF 全区与装饰箭头（`→ ⇒ ⇐ ← ↔ ↳ ➜ ⬅ ➡` 等）禁止。替代：流程用有序列表；映射写「A 对应 B」；转换写「A 转换为 B」；ASCII `->` 与 `=>` 仅限行内代码与代码块（mermaid `-->` 合法）。
3. **emoji、装饰符号与变体选择符**：U+1F000 至 U+1FAFF、U+2600 至 U+27BF、U+2B00 至 U+2B0F、U+FE00 至 U+FE0F、U+200D、U+203C、U+2049、U+2139 全禁。替代：提示警告用 GFM 警示块（`> [!NOTE]` `[!TIP]` `[!IMPORTANT]` `[!WARNING]` `[!CAUTION]`）或加粗；表格勾选用「是 / 否」「支持 / 不支持」文字。文档化 TUI 字形（状态栏图标）时字形放行内代码（豁免区）。
4. **全角字符与智能引号**：全角仅限中文正文标点白名单 `，。：；？！、（）《》「」『』·` 与省略号 `……`；全角字母数字、全角空格（U+3000）、智能引号 `“ ” ‘ ’`、代码与行内代码内全角符号一律禁止；英文整句内部用半角标点；中文引号统一直角 `「」`（本项目正文已循此例）。

## 豁免区

校验先剔除再扫描：围栏代码块（含 mermaid 与公式）、行内代码、链接与图片目标、规则定义区（黑名单与违规示例列）、第三方引文（报错原文、上游标题保持原样不「修复」）。

## 空格与混排

1. 中文与英文、数字之间加一个半角空格；数字与单位之间加空格（32 GB、100 ms），度与百分比除外（233°、15%）。
2. 全角标点与相邻字符间不加空格；不重复标点（！！禁止）；链接与相邻文字间加空格。
3. 混排句子标点以主语言为准：中文句全角，英文整句内部半角。
4. 表格对齐只用半角空格；竖线转义 `\|` 或行内代码包裹。

## 标点与结构细则

| 项目 | 规则 |
| --- | --- |
| 引号 | 中文「」『』；英文与代码直引号 |
| 书名与路径 | 书籍规范《》；文件名路径行内代码 |
| 范围 | 中文「3 至 5」或 `3-5`；英文 `3-5` |
| 并列 | 中文顿号、；英文逗号加牛津逗号 |
| 列表项末尾 | 完整句加句号、短语不加、同一列表统一 |
| 标题 | 一级全文唯一、层级不跳级、句末无标点 |
| 代码块 | 围栏必标语言（无则 text）、示例可复制运行 |
| 表格 | 表头名词短语、单元格短句 |
| 链接 | 锚文本描述目标，禁「点击这里」 |
| 强调 | 加粗为最高强调；中文慎用斜体 |

## 术语

专名保留官方大小写（API、JSON、GitHub）；缩写首次出现给全称；术语全文一致，首次「中文译名（英文原词）」；正式文档避免口语缩写（repo、asap）。

## 智能体执行规则

- 高频场景对照：插入语勿用 em dash（用冒号/括号/拆句）；流程勿用 Unicode 箭头（有序列表）；映射写「对应」；标题无装饰；提示用警示块；对比表用文字状态；行内代码内保持半角；引文放引用块保持原样。
- 输出前自检四步：逐段回查四类禁字；确认命中均属豁免区；豁免区外逐个替换；替换后重读确认语义无损。
- 系统提示词注入片段：见源规范 8.4 节（六条硬约束），本细则即其项目化形态。

## 校验

- 脚本：`uv run --script .tools\mdcharlint.py docs\ ...`（PEP 723，先掩豁免区再逐字符扫；error 级四类禁字，warning 级空格缺失、重复标点、代码块未标语言待后续）。
- 编辑器检索正则：破折号 `[–—―−]`、箭头 `[←-⇿]`、emoji `[\u{1F000}-\u{1FAFF}\u{2600}-\u{27BF}]`、全角 `[！-｠　]`、智能引号 `[“”‘’]`。
