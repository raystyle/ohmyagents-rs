> 关键词：sed、grep、PowerShell、中文路径、转义、批替换。

| 编号 | 错误现象 | 根因 | 正确处理 | 首次踩 |
| --- | --- | --- | --- | --- |
| M023 | Git Bash sed 批量替换中文加反斜杠路径静默未生效 | sed BRE 转义与多字节路径组合在该环境失配，且无报错；验证 grep 的转义又假阴性 | 跨平台批改中文路径用 PowerShell `String.Replace` 字面替换；验证用 `Select-String` 或 python `io`，不用多层转义的 grep 模式 | 2026-08-31 |
| M024 | ast-grep 模式 `fn name($$$)` 零命中 | Rust 的 fn_item 节点含 body，模式缺 body 通配即不匹配；可见性修饰也要写进模式 | 按名定位用 `pub fn name($$$) $$$`（带 body 通配与 pub）；签名级用 `fn $NAME($$$) -> Result<$RET, String> $$$` | 2026-08-31 |
