# M107-工具链与脚本错误

> 关键词：sed、grep、PowerShell、中文路径、转义、批替换。

| 编号 | 错误现象 | 根因 | 正确处理 | 首次踩 |
| --- | --- | --- | --- | --- |
| M023 | Git Bash sed 批量替换中文加反斜杠路径静默未生效 | sed BRE 转义与多字节路径组合在该环境失配，且无报错；验证 grep 的转义又假阴性 | 跨平台批改中文路径用 PowerShell `String.Replace` 字面替换；验证用 `Select-String` 或 python `io`，不用多层转义的 grep 模式 | 2026-08-31 |
| M024 | ast-grep 模式 `fn name($$$)` 零命中 | Rust 的 fn_item 节点含 body，模式缺 body 通配即不匹配；可见性修饰也要写进模式 | 按名定位用 `pub fn name($$$) $$$`（带 body 通配与 pub）；签名级用 `fn $NAME($$$) -> Result<$RET, String> $$$` | 2026-08-31 |
| M025 | ast-grep `--json` 提取 metavariable 为空 | 0.45.1 的 JSON 键是 `metaVariables.single.<VAR>.text`，不是 `meta` | 解析取 `m['metaVariables']['single']['NAME']['text']`；先看一条原始记录再写提取脚本 | 2026-08-31 |
| M026 | mq 选择器落空或报 Unknown selector `.s` | `.h.1` 是层级值选择器（非标题文本）；无 `.s`；section 模块函数必须 `-A` 聚合才拿得到全文档节点；`map()` 内嵌 section 函数触发 runtime bug | 标题节点用 `.h`/`.h1`；按节抽用 `mq -A 'section::section(., "标题含词")'`（多文件也带 `-A`）；mq 在 `D:\ohmyenv\mq\mq.exe` 不在会话 PATH，需全路径 | 2026-08-31 |
| M028 | rg 输出里目标词全变成了 `ln`，像源码被篡改 | 误写 `rg -rln "hooks"`——`-r ln` 是 `--replace ln` 替换标志，`-l`/`-n` 被吞进替换串参数位，匹配文本全被替换显示 | rg 想只列文件加行号就显式写 `-l -n` 或 `-n --files-with-matches`；看到整词被替换成无意义串先查自己是否带了 `-r` | 2026-08-31 |
| M032 | 全量 `cargo test` 偶发单例失败（单跑全绿，P0006/P0009 两现） | 测试临时目录名只到毫秒粒度，同毫秒并行测试共享目录，一例的 `remove_dir_all` 删掉另一例的夹具 | 临时目录名加进程内原子序号（`AtomicU64` 尾缀，agents/yolo/deploy/orch/tests 五处统一）；偶发二现即修不留观；提交门禁必须含 `cargo test`，只查文档三件套会带病提交（本日实犯一次） | 2026-08-31 |
| M033 | 文档门禁串联 `uv run --script .tools/md-heading-scan.py | tail -1` 后违规未拦提交 | 管道后接 `tail` 时 `$?`/`&&` 判的是 tail 的退出码（恒 0），扫描器 exit 1 被吞 | 门禁命令放管道末位或先裸跑拿退出码再接后续（`scan && git commit` 不经管道）；本次连带教训：扫描输出多行时 `tail -1` 只见最后一条，其余违规被视觉隐藏 | 2026-08-31 |
