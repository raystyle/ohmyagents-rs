# web 镜像本地化与主页化

- 状态：已完成（2026-08-31 当日达成，用户验收「可以了」）
- 日期：2026-08-31
- 关联：`P0021`（rmux web-share 集成）；用户连续定调：「share.rmux.io 不能内置到本地么」「在仓库没有原始前端页面项目么」「找找 node typescript 项目」「不需要 wrangler 部署 只在本地开 server」「修改 rmux-web-share 为本地的 web-mirror-server」「主页直接显示可视化多路窗格，配置网页去掉，agent 纯 API 或 CLI 操作」

## 背景与问题

P0021 集成了 rmux web-share（官方域前端）。用户要求完全本地化（不出 127.0.0.1）、且要找到前端源码项目自建。随后两次形态定调：能力命名 **web-mirror-server**（可视化后台 agent 任务）；`oma serve` 主页直接就是这个镜像页，原配置 dashboard 删除，编排操作回归 CLI/API/MCP。

## 方案与过程

### 一、本地化三连挫与根因

抓官方静态产物自托管，连续四挫（每次一个真根因）：

1. `/share-fe/` 尾斜杠未注册 → axum 精确匹配 404。
2. 误判前端连官方中继 → 补 `#e=` endpoint 参数；实则默认 endpoint 就是本地网关 `ws://127.0.0.1:9777/share`（bundle 里 `ei` 常量），补错参数反而坏。
3. **缺 WASM**：前端是「HTML/JS/WASM」应用，加密栈 `rmux_web_crypto_wasm_bg.C8R0tHIf.wasm` 以**绝对路径 `/_astro/`** 引用（JS 带 SRI 锁字节不可改），没托管它 → `wasm_crypto_unavailable` → 页面空白。修：serve 根路径原位托管。
4. **ACAO**：css/js 标签带 `crossorigin="anonymous"`，真实浏览器按 CORS 协议校验，响应无 `Access-Control-Allow-Origin` 就拒载（官方 CDN 带）——「终端正常、样式全丢」的真身。

### 二、源码仓发现与构建

- 用户点破后重查：`Helvesec` 名下有 **`rmux-web-share`**（前端全源码：Astro 6 + xterm.js 5.5 + web-links/image addon + qrcode + Playwright 测试 + wrangler 部署配置；build 管道含 wasm provenance 校验、SRI inject、bundle 预算）与 **`rmux-typescript`**（TS SDK）。主仓 `crates/rmux-web-crypto` 即 WASM 的 Rust 源码（E2EE：X25519 + ML-KEM-768 混合 + ChaCha20-Poly1305）。
- 本地构建：`npm ci && npm run build`。坑：Windows git 检出 autocrlf 把 `wasm/README.md` 转 CRLF，provenance hash 校验失败——`git clone -c core.autocrlf=false` 重克隆即过（**provenance 类校验对行尾敏感，Windows 检出必须关转换**）。
- 产物 `dist/`（1.7MB，32 资产）部署到 `docs/web/share-fe/`；源码树 `docs/web/share-src/`（node_modules/dist 进 gitignore）。

### 三、serve 目录托管

静态写死路由换成目录服务：`/share-fe/{*path}` 与 `/_astro/{*path}` 运行时读盘（`CARGO_MANIFEST_DIR` 编译期锚定，任意 cwd 可跑；路径逐段规范化防穿越——`../` 形态 404），扩展名 MIME 表，全响应 ACAO + no-store。**前端 rebuild 后不用重编 oma**。

### 四、session scope 与免 PIN

- 真路结论（源码 `record.rs`/前端 `setReady` 逻辑）：**窗格操作（分屏/布局）与完整编辑只在 operator + session scope 解锁**（`e.controls && e.scope==="session" && e.role==="operator"`）；pane scope 无窗格操作。
- `api::web_share` 的 agent 参数改 `Option`：None = **整会话镜像**（一个 URL 全窗格），Some = 单 pane。
- **免 PIN**：`--no-pin`（服务端 `check()` 对无期望 PIN 直接放行，不降级角色）。策略：本地托管形态（serve 起、前端本地）自动免 PIN；官方域外发面（CLI `oma web` 默认）保留 PIN，`--no-pin` 显式关。

### 五、主页即镜像

- `GET /`：清本项目全部旧 share（pane 形态 target 是 `<session>:%N`，前缀匹配）→ 起整会话 operator 镜像（ttl 12h）→ 200 直出前端 HTML 并注入 shim `<script>if(!location.hash)location.replace('/#t=<token>')</script>`（302 方案对 `/` 自旋；shim 一次自载后前端按 hash 连接）。
- 原 dashboard（`docs/web/index.html`）**删除**；编排六操作走 CLI / `--json` / MCP / RESTish API。banner 打 `serve.addr`（即主页）。
- 命名口径：**web-mirror-server**（可视化后台 agent 任务）。

## 实施过程与经验

- 本地化四连挫的共同教训：**静态分析 minified bundle 有上限**（`ei` 常量、绝对路径 wasm、ACAO 依赖都是读不出来的运行时行为），每挫一个真根因；用户 console 一行报错（`index.D2bSaP4U.css 404`）比十次盲试值钱。
- **平台资产先找源码仓**：`gh api users/<org>/repos` 列全仓一发命中 `rmux-web-share`——之前只查主仓就下了「前端不开源」的结论，错在搜索面不全；用户两次追问把路逼正。
- Windows 检出 CRLF 破坏 provenance 校验：凡带 hash 校验的仓库（provenance/SRI/lockfile），clone 一律 `-c core.autocrlf=false`。
- 「打开即用」的最后一公里是 hash 注入而非重定向：302 到 `/#t=` 对根路径自旋，200+条件 shim 一次自载即稳。
- serve 常驻与测试抢 exe：`CARGO_TARGET_DIR=target-test` 隔离构建跑门禁，不动运行中的 serve。
