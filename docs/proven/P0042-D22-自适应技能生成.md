# D22 oma 自适应技能生成

- 状态：已完成（135 单元加 21 集成全绿；用户级技能已刷新）
- 日期：2026-09-10
- 关联：PRD D22；Agent Skills 标准；D20 收窄后的命令面

## 背景与问题

用户级 `~/.claude/skills/ohmyagents/SKILL.md` 是旧手写版，挂着 D20 已删除的 token / secrets / login 面；项目级 init 生成物靠手维护 COMMAND_MAP，一天内两次过期。用户裁定：按 SKILL 标准整理 oma 自己的技能，且内容从命令自适应输出。

## 方案

- `oma skill`：从 clap 活命令树递归渲染 SKILL.md：frontmatter 按 Agent Skills 标准（name 加 description 含何时用）；命令表 = 子命令路径加位置参数加长旗标（用法串带 value_name），说明取各命令 about；新命令 / 新旗标自动出现，零手维护。
- `--write` 落用户级 `~/.claude/skills/ohmyagents/SKILL.md`（幂等覆写）；升级后重跑同步，正文标注勿手改。
- 配套：位置参数 value_name 汉化（`[名]` `<关键词>` 等，--help 同步受益）；Cli 的 about 硬编码删除，回落 Cargo.toml description 单一源（顺带修掉过期 token 措辞）。
- 双层记档：项目级 init 生成物（COMMAND_MAP 加 marker 覆写语义）不动：lib 拿不到 bin 的 Cli 树，两层面各管各的（R002 2.6）。

## 落地与验收

- `src\skillgen.rs`（渲染器加两件单测：frontmatter 与自适应判据「树加子命令即出现」）；`oma skill --write` 实写用户级技能并清掉旧 token 面 [实证： 本机]。
- 135 单元加 21 集成全绿；COMMAND_MAP 加 skill 行重跑 init 再生四家 SKILL。

## 经验

- 自文档面（skill / help / 补全）要挂在单一事实上：命令树本身就是权威，手抄一遍就多一处过期点（COMMAND_MAP 一天两过期为证）。
