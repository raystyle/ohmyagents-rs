# 官方 web 镜像集成

- 状态：已完成（2026-08-31 当日达成，三面验收过）
- 日期：2026-08-31
- 关联：用户定调「和官方的 demo 一样」＋点破「我们的 tmux 不是有 webshare 功能」；前置 P0019（自建 SSE 镜像）、`P0001`（xterm.js 镜像本是原始愿景）

## 背景与问题

P0019 的 `/screen` 是纯文本快照镜像（无色、无键入）。用户要的是 web-claude-demo 同款：真终端、可操作。中途自建过一版 xterm.js 桥（WS 转发原始字节 + `keyboard().type_text` 回键 + resize 同步，协议照抄 demo 源码），实测**内容乱**——Oldest 回放的 backlog 已滚过头（pane 存活数分钟、TUI 动画刷屏），xterm 从断头 ANSI 流重演必乱；demo 没事只因它的 pane 是页面加载前刚建的。用户随即点破正解：**rmux 原生就有 `web-share`**。

## 方案

oma 不造终端仿真轮子，接管 rmux 官方 web-share（本地网关 127.0.0.1:9777，前端 share.rmux.io，operator 真可操作 attach、spectator 只看、PIN、TTL、断开管理全内建）：

- **api 层**：`web_share(root, agent, spectator, ttl)`（调 `rmux -L <label> web-share -t %N --operator-only|--spectator-only --ttl`，**URL/PIN 在 stderr**——`run_cli_checked` 只回 stdout 会丢，直接用 `run_cli` 合并两路解析）、`web_shares`（list）、`web_share_stop`（--disconnect）。
- **HTTP**：`POST /share/{agent}`（body `{spectator, ttl}`）、`GET /share`、`DELETE /share/{id}/stop`。
- **CLI**：`oma web [agent] [--spectator] [--ttl N] [--project]`——缺省全会话各起一路，打印 URL/PIN/过期。
- **网页**：状态卡每路加「官方镜像」按钮，起 share 后卡内显示可点链接与 PIN。
- **自建 xterm 桥整体下线**：tui.html、vendor 三件（xterm.js/fit/css）、`/tui` 与 `/tui/{agent}` WS、axum `ws` feature 与 futures 依赖全撤。

## 验收标准与结果

- CLI：`oma web claude --ttl 1800` 打 URL（share.rmux.io/#t=…）、PIN、过期行；operator 模式标注。过。[实证]
- HTTP：list（含 CLI 起的活动 share）、POST grok 得 pin、DELETE stop 返回 ok。过。[实证]
- 用户浏览器开 operator URL + PIN 直操 claude TUI（demo 同款保真与可操作性）。过。[实证: 用户验收]

## 实施过程与经验

- **用户两次纠偏定的方向**：先「不是配置页，要 TUI 镜像」（自建桥），再「rmux 不是有 webshare」（集成官方）。第二次纠偏前的弯路有价值：坐实了「原始字节回放 + xterm 自演」在长活 pane 上必乱（backlog 断头），也摸清了 demo 的 WS 协议——**平台已有能力 > 自建兼容层**，这是懒人阶梯第一档在产品层的复现。
- web-share 的输出面在 stderr（`operator URL emitted on stderr` 明说了）：CLI 包装函数先看返回再定接口，`run_cli_checked` 的 stdout-only 契约会静默丢 URL。
- Windows 多 feature 配置共享 `target\debug\oma.exe`：**最后的构建决定 exe 形态**——一轮无 feature 的 `cargo test` 会把 feature 版覆盖掉，随后 serve 报缺 feature；给用户起 serve 前必须 `--features server,mcp` 重建（本轮实踩一次，排查靠前台跑看真实报错）。
- TaskStop 杀 shell 不杀 Windows 子进程：oma.exe 残留占端口，旧二进制 404 假象；`taskkill //F //IM oma.exe` 清场后再起。
