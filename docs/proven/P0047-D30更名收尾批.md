## 关键机理记档

- **sweep 的成对语义清单**：文件名环与内容标记、marker 写入与检测、目录名与 frontmatter name 三对成对面，单侧换名即断链，更名收尾要按「对」过而不是按「串」过 [经验： D30 实作总结]。
- **迁移用例来自文档路径**：按 README 安装步骤走一遍即得「bin 先建根」组合，三用例单测未覆盖；D30 新增用例 d30_bin_first_root_still_merges_legacy（bin 保留、定制迁入、旧根摘除、撞名残留旧根保留）。
- **0x08 退格控制字符**：`.hst\bin` 在 CHANGELOG 与 PRD 里曾被吃成 `hst` 加退格加 `in`（肉眼读「.hstin」，文本匹配不上）；mdcharlint 四类禁字不含控制字符，侦测用 `rg 'hst.in'` 类点通配或直接扫 [char]8。
