# 各功能部件POC验证原型

- 状态：进行中
- 日期：2026-08-29
- 关联：`GOAL.md` 当前目标；研究 `docs\research\rmux-sdk最佳开发实践与验证poc.md`；方案 0001 首期切面、0003 `oma check`

## 背景与问题

文档骨架、定位、`oma check` 已落地。产品命令（spawn / send / init / doctor / cleanup / 网页）尚未实现。用户定调：**先做各功能部件需求的 POC 验证原型**，再叠成 `oma` 产品命令。避免一次写完整编排器却在 drive / 布局 / 清理上踩已知坑。

## 目标与非目标

- 目标：
  - 按部件拆最小可跑原型，每件有验收：退出码 + 可观察产物
  - 落 `examples/poc-*.rs`，`cargo run --example poc-<名>`
  - 用 `rmux-sdk = "=0.10.0"`；缺一等 API 再走协议/CLI 逃生舱
  - 闸门：`oma check` 已绿（本机 Windows 已装 0.10.0）
- 非目标：
  - 本轮不实现完整 `oma spawn` / REPL / 网页 HTTP
  - 不先上四路真实 agent（布局/drive 用 pwsh echo 桩）
  - 不 `kill-server`、不默认弹浏览器、不抄 CreateOrReuse 叠窗格

## 方案

部件与 POC 一一对应。会话名 `oma-poc-<部件>`，专用 pipe/socket，结束只 `kill-session`。

| 部件 | example | 验证什么 | 状态 |
| --- | --- | --- | --- |
| check | `oma check` | pin 版本、归档哈希、tiny+helper+daemon | 已完成（Windows） |
| yolo | `poc-yolo-doctor` + `oma init --yolo` | 项目级无阻塞键；`--pretrust` 才写家目录信任库 | 已完成（Windows） |
| doctor | `poc-yolo-doctor` + `oma doctor` | 只读 yolo/trust/binary/state；不 attach；block 退出 1 | 已完成（Windows） |
| endpoint | `poc-endpoint` | 显式 `WindowsPipe`/`UnixSocket`，非 Default | 已完成（Windows） |
| session | `poc-session` | CreateOnly 撞名失败；ReuseOnly 可接；cleanup 后本会话消失 | 已完成（Windows） |
| layout | `poc-layout` | 2x2 `split_with` + argv；四格 pid 活 | 已完成（Windows） |
| drive | `poc-drive` | `send_text` 与 `send_key(Enter)` 分发；短头离开输入 | 已完成（Windows） |
| dialogs | `poc-dialogs` | hook 写 blocked（state 文件）+ sendkeys 点假 Allow 框 | 已完成（Windows） |
| paste | `poc-paste` | LoadBuffer + PasteBuffer 中文；不自包 `\x1b[200~` | 待办 |
| locate | `poc-locate` | pid 反查进程名；错位 throw | 待办 |
| observe | `poc-stream` | `output_stream` 收到 echo 字节 | 待办 |
| judge | `poc-state` | 写/读 `.ohmyagents/state` idle/working；Quiet 不当 idle | 待办 |
| init hook/skill | `poc-init` | 只在临时项目目录落 hook/skill 文件，不改家目录 | 待办 |
| 负例 | `poc-negatives` | 禁止路径不进主流程：`C-c` Codex、warn-and-continue、kill-server | 待办 |

实现约束：AGENTS 第 9 条选库；第 7 条 Drive 铁律。详细 API 对照见 `rmux-sdk最佳开发实践与验证poc.md`。

## 备选方案

| 做法 | 取舍 |
| --- | --- |
| 直接写 `oma spawn` 四路 | 否：部件未核，失败难定位 |
| 只跑官方 sdk_demo_* | 否：CreateOrReuse、默认端点、Enter 同文本，与本仓铁律冲突 |
| 每个 POC 独立 crate | 否：本仓 `[[example]]` 足够 |

## 实施步骤

## 风险与回滚

- Job Object `os error 5`：记 MISTAKES；POC 用 WMI 在 job 外拉起 daemon 再 `connect()`，不当默认 kill-server，不把 wt 当默认
- paste 协议构造失败：退 CLI `paste-buffer -p`
- 回滚：删 example 会话名；不碰用户其它 rmux 会话

## 验收标准

- 每个待办部件有 `examples/poc-*.rs` 且本机 `cargo run --example …` 退出 0。pane 最小集（endpoint/session/layout/drive/dialogs）已在 Windows 验收；Linux/mac 委托后续仓库
- 负例不作为「成功路径」合入 `src/`
- `oma check` 仍绿；POC 不调用 `kill-server`
- 清单、GOAL/TODO/PLAN 与磁盘一致
- 完成后在 `docs\diary\` 补一笔；方案回填「实施过程与经验」
