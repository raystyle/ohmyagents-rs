> 2026-09-02。用户定调：codex 与 claude code 用变量配置提供商 url、密钥、模型名，rmux 编排按变量参数指派 agent 用指定提供商与自定义模型；别名任意组合（智谱/deepseek 各自兼容 claude 与 codex）；密钥密文落盘、内存解密、调度 env 注入；标准 sops 配置格式兼容其它 CLI。参考仓 `D:\sourcecode\core`（model_lns 模式）。

## 需求

## 关键结论

### 1. 四格官方矩阵

> zhipu 与 deepseek 对 claude/codex。

[实证: 官方文档抓取 2026-09-02，browser-harness web-fetch 加 Mintlify .md 原文]

| 组合 | 端点 | 注入形态 | 模型码 |
| --- | --- | --- | --- |
| claude × zhipu | `https://open.bigmodel.cn/api/anthropic` | env：`ANTHROPIC_BASE_URL` 加 `ANTHROPIC_DEFAULT_*_MODEL` | glm-5.3 / glm-5.3-flash |
| claude × deepseek | `https://api.deepseek.com/anthropic` | env：BASE_URL/AUTH_TOKEN/MODEL 加 OPUS/SONNET/HAIKU/SUBAGENT/EFFORT_LEVEL/AUTO_COMPACT_WINDOW（官方八变量） | deepseek-v4-pro[1m] / deepseek-v4-flash |
| codex × deepseek | `https://api.deepseek.com/`（wire_api responses，env_key DEEPSEEK_API_KEY） | argv：`-c model_provider=… -c model=… -c model_providers.*`（codex 0.149 `-c` 运行时覆写，`codex --help` 实证） | deepseek-v4-pro |
| codex × zhipu | `https://open.bigmodel.cn/api/v1`（OpenAI Response 协议；官方 Coding Plan 页） | argv：同上（provider 名 ZAI）；前置 `~/.codex/models.json` 声明 GLM 模型元数据 | glm-5.3 / glm-5-turbo |

- deepseek 官方模型映射：claude-opus* → deepseek-v4-pro、claude-haiku/sonnet* → deepseek-v4-flash（Claude Code 场景）。
- 智谱 Anthropic 兼容与 OpenAI 协议三端点分工：`/api/anthropic`（Anthropic Message）、`/api/coding/paas/v4`（Chat Completion）、`/api/v1`（Response——codex 专用）。

### 2. oma 注入机制

> 已落地。

[实证: 单测 profile_alias_injects_env_and_argv 与 CLI 冒烟]

- **存储**：`~/.ohmyagents/providers.toml`（OMA_HOME 可重定向）——`[providers.<别名>.<agent>]` 下 `env` 图与 `argv` 数组。**标准 sops 托管**：文件带 `[sops]` 元数据时调度经 `sops -d` 内存解密（密钥密文落盘、明文只在本进程与 pane env）；明文形态兼容过渡；其它 sops 兼容 CLI 同格式可读。
- **注入**：`oma spawn --agents claude@zhipu,codex@deepseek`——`split_agent_profile` 拆名、`resolve` 查簿、argv 依序追加、env 并入 pane ProcessSpec（BTreeMap 确定性序）。
- **持久**：`ManifestAgent.profile` 记录别名，respawn 与和解路径沿 manifest 复注入（argv+env）。
- **观测**：`oma agents providers` 列别名 × agent × env 键名（不回显值）；`--example` 出官方四格模板。

### 3. 密钥策略

- 现役：token 沿系统级 env（用户 ANTHROPIC_AUTH_TOKEN / DEEPSEEK_API_KEY 已在环境），别名簿不落明文。
- 目标：`sops` 托管后密钥值入簿为密文；age+sops 体系（remotex_rs 蓝本，任务 #11）承接身份与解密。
