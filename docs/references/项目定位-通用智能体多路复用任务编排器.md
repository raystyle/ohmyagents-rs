# 项目定位：通用智能体多路复用任务编排器

> AGENTS「项目定位」的展开。现役定位以本文件为准。演进：方案 0001 是首期切面，方案 0002 是上一版措辞，方案 0004 定调本定位与显示名 Oh My Agents。

## 本质

Oh My Agents（仓库名 `ohmyagents`，CLI 二进制 `oma`）是**通用智能体多路复用任务编排器**。

- **多路复用**：在 rmux 会话里把多路终端智能体编进同一个项目工作区，一条 CLI 操作它们。
- **任务编排**：下发任务、看状态、收尾；能开浏览器时可选镜像各路 TUI。
- **自动配置**：按各家规则在启动的项目目录部署 hook、skill、启动参数和信任预写，不把配置写成用户家目录全局默认。
- **通用**：智能体集合可扩展。当前默认适配 Claude、Codex、Grok、Kimi，不是产品上限。

## 边界

- 编排钉在启动的那个项目目录，不替代 ohmypwsh 的五端环境总台。
- 不替代 claude / codex / grok / kimi 本体，只配置它们、驱动它们。
- 运行时后端是 rmux，不引入 herdr 当宿主。
- CLI 是编排入口；网页不是主控。弹不出浏览器时编排仍完整。

## 两个平面

| 平面 | 宿主 | 缺席时 |
| --- | --- | --- |
| 控制与编排 | `oma` CLI | 不可缺席 |
| 观察 | 可选 HTTP 与终端镜像 | `--no-web` 或无浏览器，任务仍跑 |

## 约束在一个项目

启动 cwd 或 `--project` 就是唯一工作区。`init` 把各家项目级文件写进该目录。状态在 `<project>\.ohmyagents\state\`。信任库（各 agent 记在用户家）可以预写；hook 注册不写家目录。
