## 自省

- **「缺」的判据取决于探测面**：`bash -lc which` 说 lan-linux 四家全缺，oma 多级探测（PATH、env、oma root、default locations）找到 kimi；盘点结论必须写明用什么探的，换工具重验再下结论。
- **后台命令禁止 `| tail` 截输出**：交叉编译首跑失败被 tail 吞了错误细节、exit 0 假象（管道吃掉退出码）；后台任务要全量落盘再 grep。
- **WSL `/tmp` 不是持久位**：实例空闲回收后 `/tmp` 清空，构建产物消失；跨调用产物一律落 Windows 盘（`target-linux` 持久目录进 .gitignore）。
- **部署位旧构建会遮蔽源码事实**：`--version` 源码早在（eeb3400）而三端部署位全是旧件，「功能缺失」先分辨源码与部署位再动代码。
