## 关键裁决

- 分层就是单元 + 集成两层（社区补 doctest 成三层）；冒烟/回归/验收是意图标签，分别落在 exit 0 断言、黄金文件（或 insta 快照）重跑、oracle 对比上。
- 三源原则收敛：测行为不测实现（MS 明说能集成就不单元）、一个测试一件事、少 mock 多真替身、性能与正确性分离——变的只是工具，oma 全程真 daemon 集成与此一致。
- MS 独有的两条硬规则进本仓口径：测试设施收 `test-util` feature；禁止重言式测试（AI 协作仓最高优先，期望值必须来自独立来源）。
- 规则与研究的分工：研究是为什么（三源对照、可推翻）；细则与 AGENTS 是做什么（硬约束、随研究更新）。测试绿是 [实证] 的最强依据，研究断言可引用测试名。
- 现代层按阶段引入不一步到位：本目标只做 tests/cli.rs 与本地 fmt/clippy/test --locked 门禁；nextest、insta、CI 门禁等各设触发条件。
- 综述中未核实的量化断言（nextest 加速倍数、RustRover 集成）按 [记忆] 待复核，不进结论、不进规则。
