## 做了什么

- **取证先行**：S015 矩阵复核官方文档（claude exec form 按 PATH 解析、无 per-OS 字段；statusline 走 shell 路由）；盘上实锤破坏面（codex 双字段皆 `/mnt/d`）；Node spawn 无扩展名补 `.exe` 实测；Plan 子代理产出合并语义设计（`probe_hit`/`OsSide` 注入）。
- **hook 注册自适应**：PATH 探针 bare 形态（粘性不降级）+ codex 字段所有权；双环境第二轮起注册文件字节不变——see-saw 死刑。
- **状态通道全覆盖**：`oma hook --agent` 无 env 回退写项目状态文件；记录带 session；状态栏会话闸拦死会话遗留态。本会话（用户手拉）PreToolUse 实时写 working 目验。
- **状态栏重铸**：UTF-8 根修、starship 风格（旗标/版本段/完整路径）、Catppuccin 配色、oma 段 `agent:state` 机读标记、shell 段三平台探测（mac 走 ps 兜底）。图标全部经用户字体 cmap 实证（fontTools 按名搜），不猜码位。
- **S025 研究**：kimi/grok 状态栏配置矩阵一手取证（子代理浅克隆），四家全部支持命令驱动——机读标记体系的地基。

## 学到什么

- 共享目录跨环境的本质：**绝对路径是环境态，bare 名是环境无关态**；codex 的 per-OS 字段是「一份注册双环境」的官方出口。
- 状态栏不只是装饰，是**画进 TUI 的机读信号通道**——rmux 编排扫屏（expect_visible_text）即可消费，覆盖 hook 够不着的用户手拉会话。
- nerdfont 图标必须对用户字体 cmap 实证：cmap 有映射 ≠ 有字形（F0A0A 映射但不显，EBC7 实显）。
- 用户的高频定调流（十一轮）里，方向会连续收敛（项目名→agent:state、截断→完整路径、emoji→nerdfont）——实现要小步快跟，别一次押注。
- rustfmt 工具链漂移会让全仓 `--check` 爆红：发现就修（用户定调），fmt 进门禁。

## agent doctor 部署诊断落地

> 傍晚切片。

- doctor 加 `Status::Warn` 层：部署缺口（登录缺失、状态栏未配、会话死路）只诊断不进 `blocked()`，block 语义仍只对交互阻塞负责——契约测试钉死新四类检查永不 block。
- 四类新检查：登录态（grok `auth.json` RFC3339 加 create_time 加 30 天兜底加 300s 提前量；kimi credentials hasToken 加空串墓碑区分吊销与未登录）、hook 形态（`hooks.form` bare/absolute；codex per-OS 字段 command/commandWindows 各侧检出）、状态栏（四家 oma bar 配置标记加脚本在位加 pwsh 咨询）、会话健康（`agent=oma check=session`，manifest 在才 rmux 只读探活，无会话不误报）。
- 测试即取证的坑：codex per-OS 测试暴露 `is_ours` 对 `& "exe" hook` 形态失明（首 token 是 PowerShell 调用操作符）——doctor 跨环境漏检 Windows 字段、deploy 换 exe 路径后旧条目被当外来者重复追加。剥前导 `&` 根修于 deploy 源头（改在源头不在消费方）。
- 选型：grok `expires_at` 是 RFC3339，加 `time` crate（只开 parsing feature，不自写日期解析）。
- 验收：105+12 全绿、fmt 过、clippy 存量 20 条不新增；Windows 侧全 ok（codex 双侧字段互检过）；WSL 侧如实报 grok 未登录与状态栏未配 warn——部署诊断该有的样子。

## oma agents login 设备码引导落地

- 形态修正：S026 原推断「pane 加扫屏」被源码实证推翻——两家登录流输出都是纯 eprintln / process.stderr.write、无 TTY 依赖（grok-build auth/device_code.rs 355-390、kimi-code login-flow.ts 46-69），子进程捕获即可，与 agents 探针同形态、免 rmux 依赖。
- 解析坑：grok 提示行与值之间有 eprintln!() 空行——黄金样例测试当场抓住「取下一行」的错，改为取下一非空行。测试即取证的价值再次兑现。
- 成功判据不单信标记：退出 0 且 doctor 登录态判据（落盘凭据）过才算 `login.ok=true`；超时杀进程、失败带 login_state 与最后失败行。
- 实机验收即产品使用：WSL 侧 grok 真登录（doctor 报的 warn 真缺口），URL/code 机读标记精确转发、用户浏览器确认、后台流完成。
- WSL 真登录后半程修正：用户忙于重装 rust 未完成浏览器授权，grok 轮询 token 端点遇 TLS 断连（rustls unexpected EOF）退出——oma 失败路径全对（`last=Error:` 失败行捕获、`login_state=warn?`、exit 1）。成功半程（凭据落盘 doctor 确认）待用户闲时重跑，先如实修 GOAL/TODO 口径——验收没走通就不写走通。

## secretguard 落地

- `oma hook` 第二职责：PreToolUse/UserPromptSubmit 命中 block 级密钥 exit 2（stderr 掩码原因回模型）、PostToolUse 观察、fail-open；guard 与 state 写互相独立（state 文件推不出来也照拦）。
- 八层防误报全落地：精确前缀 27 模式、实值比对（env 25 名单 + providers.toml 明文；sops 密文不起子进程）、熵值门 3.5、stopwords、password warn-only、掩码前4后4、语料运行时拼接（oma 源码不落字面密钥，自家 guard 不误伤自家开发）。
- 坑两枚：raw string 里 `\"` 直接终止字符串（引号类正则改 r#"..."#）；URI 语法组 `(ql)?` 占了 1 号捕获组，熵值门对着 "ql" 误杀——命名组 `(?P<v>…)` 圈值部，黄金测试当场抓住。env 并发竞态提模块级共享锁。
- 顺手件：hook 事件推断补 codex 无事件名字段的形状推断（tool_response→post、tool_name→pre、prompt→submit），codex 状态面从 unknown 变实判。
- 验收：126+13 全绿（12 新例）、CLI exit 2 集成例、实机冒烟掩码原因精确；guard 随下次 oma 重装/自更新激活，本仓 dogfood。

## 扫屏层消费落地

- `oma status` 三面（marker 行 / TTY 表 / api JSON）加 screen 扫屏列与 check 交叉核对（match/mismatch/-）；终端态与扫屏态**同一次快照出**，扫屏零额外开销。倒序扫可见行取最后一次绘制（重绘后旧标记不作数）。

- doctor 刻意不加扫屏（不 attach 不连 daemon 是它的边界），记进 S025。

## 密钥一钥两密文与四 shell 懒注入落地

- oma 彻底接管 agent 密钥面：存储对齐 ohmycloud D20（app.key → AES-256-GCM 包 age 身份 → SOPS vault，解密链全程内存），投递对齐 ohmypwsh 懒注入（交互 shell 启动现场解密写会话 env，明文不常驻注册表）。
- 选型纪律：AES-GCM 用 RustCrypto aes-gcm、身份解析与 recipient 派生用 age 官方 crate、vault 加解密走 sops 二进制——SOPS 格式零自写。
- 实机即验收：ohmypwsh 密文平移走 `sops -d | base64 -d | oma set` 管道（值不过 argv 不过记录）；pwsh `AK=True DS=True`、bash `AK=set DS=set URL=bigmodel` 端到端通。
- oma 数据根自管（用户定调）——全部落 ~/.ohmyagents 不碰 .omcf；新 oma cargo install 就位，secretguard 同批激活本仓即刻 dogfood。
