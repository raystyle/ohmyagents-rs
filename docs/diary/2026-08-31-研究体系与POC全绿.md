## 追记：S021 linux 预备检测研究

用户抛来「所有 agent 跑不起来」的问题类框架（预编译二进制 AVX-512/AVX2 与目标机不匹配、启动即 SIGILL），点名沉淀为 P0012 的预备检测文档。公开案例两条主线都核实到 issue 级：codex 的 Rust 原生踩 AVX-512（openai/codex 17410、25367），claude code 的 Bun 踩 AVX/AVX2（anthropics/claude-code 50466 族）——Bun 系与 Rust 系各踩一层，与用户给的谱系吻合。落点裁决：检测入口挂在 oma 已有的逐二进制 `--version` 探针上（exit 132 = 128+SIGILL），不另造 CPU 检查器——探针测的是制品与机器的组合，天然覆盖 CPUID 有而 XCR0 无、hypervisor 谎报两类 flags 检测盲区。Linux 面断言全部标了待实机复核的记忆态，环境切换时按六态升级。
